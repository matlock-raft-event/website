# Colours

Five inks from the logo plus river teal. Three section surfaces, one frame colour,
two accents that never paint a section. Every family is `base / light / dark / contrast`,
where `contrast` is the text colour that passes WCAG AA on the base.

### Usage rules

- Sections may only be **cream, river or pine**; the page frame is **pine-dark**.
- **Sun** never fills a section — marquee ribbon, highlighted words, icons, donate button.
- **Raft red** means "you can act here": primary buttons, eyebrow labels, dates. Never decoration.
- Hovers, borders and button undersides use the family's own `-dark` shade — no new hues.
- Text on river/pine is cream or white; text on cream/paper is ink.

## Status colours

For messaging, form states, banners and badges — deliberately separate from the brand
accents so "red button" never collides with "error text". Bases pass AA as text on
cream/paper and take white text as backgrounds; each has a pale `-light` wash.

## Tailwind usage

All families are `@theme` tokens, so the full utility set exists for each:
`bg-pine`, `text-river-contrast`, `border-sun-dark`, `bg-success-light`,
`text-error`, and so on. Component palettes (`Section`, `Heading`, `Button`)
take the family name as a prop.
